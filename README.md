# AI Hair & Beauty Intelligence Platform

B2B distribution, sales & inventory management system for a hair and cosmetics business.

## Structure

```
/backend     - Laravel 12 REST API
/frontend    - React 19 SPA
/docs        - Source documents (PRD, App Flow, Tech Stack, Design System, Schema, Plan)
/ops         - Deploy scripts, cron, env templates
```

## Quick start

See `/docs` for full documentation. Tech stack: PHP 8.4 / Laravel 12 / PostgreSQL 17 / React 19 / TypeScript 5.9 / Vite 7 / Tailwind CSS v4.

Target launch: 01 August 2026.
